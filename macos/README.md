# Codex Battery for macOS

在「设置 → 语言」里可选择跟随系统、中文、日本語或 English。手动选择会在重启后保留。

从 `~/Applications/Codex Battery.app` 打开。双击应用会显示额度窗口。关掉窗口或按 ⌘W，电池会留在菜单栏。按 ⌘R 手动刷新，按 ⌘Q 退出。窗口和菜单均提供设置入口。

每个可用的额度周期都显示剩余百分比、本地重置时间和倒计时。如果账号只提供每周额度，菜单栏会自动显示该周期。有两个周期时可以选择一个，或跟随剩余较少的周期。连接失败后，窗口把上次读数标成历史数据，菜单栏电池显示横线。

宠物自动跟随这台 Mac 上 ChatGPT 工作模式选中的 Pet。切换内置角色、自定义角色或关闭 Pet 后，电池工具会跟随更新。「设置 → ChatGPT Pet」可查看同步状态、手动重新同步，或仅在电池工具中隐藏宠物。新选的云端自定义角色需要先由 ChatGPT 在本机加载图像；等待期间只显示电池。

访达和程序坞的应用图标使用同一个角色，配有绿色电池。关闭或隐藏 Pet 后，图标会变成纯电池。程序运行时会跟随 Pet 的变化；退出时，访达保留最后同步的图标。原安装位置中的本地签名副本会在图案改变时准备并验证新副本，再整体替换；其他位置的副本仅更新运行中的程序坞图标。

「设置 → 菜单栏图标大小」提供小、标准、大三档，默认用小号。完整人物按比例显示在电池旁边，电池内显示剩余百分比。菜单栏空间特别紧张时，可启用「紧凑菜单栏（仅电池）」，人物仍显示在窗口中。按住 ⌘ 拖动电池可以调整顺序。

「设置 → 窗口宠物大小」可将人物独立设为 32、44 或 64 点。拖动窗口边缘可以调整并记住窗口尺寸。窗口较窄时，两张额度卡会上下排列，空间不足的内容可以滚动，底部的设置按钮始终可用。

默认每 60 秒检查额度，也可以选 30 或 120 秒。失败后会延长自动重试间隔，手动刷新随时可用。Mac 休眠时暂停读取，唤醒时立即更新。低电量、屏幕休眠、紧凑模式、隐藏宠物、关闭眨眼或使用「减少动态效果」时暂停眨眼。低额度提示音默认关闭。

数据来自本机已登录的 Codex CLI 的 `account/rateLimits/read`。用量推送会触发完整读取。额度保存在内存中，显示偏好保存在用户设置中。

## 构建与验证

在 macOS 上运行 `zsh build.sh`。构建产物是项目内的 `Codex Battery.app`。在已登录的用户会话中运行下列命令可以检查额度连接和图标渲染。

```sh
'./Codex Battery.app/Contents/MacOS/CodexBattery' --probe
'./Codex Battery.app/Contents/MacOS/CodexBattery' --probe-pet
'./Codex Battery.app/Contents/MacOS/CodexBattery' --self-test /tmp/codex-battery-preview.png
```
