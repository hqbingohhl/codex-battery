# 界面字体

这三份静态 TrueType 字体只在 Codex Battery 进程内加载。字体由 Google Fonts 仓库中发布的 Noto Sans SC 和 Inter 派生，均遵循随附的 SIL Open Font License 1.1。上游版本为 06bfe0d62a98375cb09c942fa18e68bd32cff057。

* Text.ttf 使用 Noto Sans SC 的 400 字重，保留原字体的字符覆盖范围。[上游文件](https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/notosanssc)
* Medium.ttf 使用 Noto Sans SC 的 560 字重，保留标题、周期名称和固定界面文案所需的字符。[Noto 许可证](Noto-OFL.txt)
* Numerals.ttf 使用 Inter 的 500 字重和 32 号光学尺寸，并将数字设为等宽，保留百分号、破折号等显示字符。[上游文件](https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/inter) · [Inter 许可证](Inter-OFL.txt)

派生字库使用 CB Interface Text、CB Interface Medium 和 CB Interface Numerals 三个名称。上游版权及许可信息保存在字体及随附的 OFL 文件中。
