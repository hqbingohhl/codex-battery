# Codex Battery · Windows 便携版 1.9

将 ZIP 完整解压，双击 **CodexBattery.exe**。请保留旁边的 Assets 文件夹。压缩包已包含可运行程序，面向 Windows 10 / 11 和 .NET Framework 4.8 或 4.8.1，以普通用户身份运行。

从旧版升级时，请先在旧窗口的「设置」或托盘右键菜单里点「退出」，再解压新版并启动。解压到原目录可继续使用原快捷方式；换目录时可以在新版设置里重新创建快捷方式。点窗口右上角的 × 会把旧版收进托盘。新版会沿用同一 Windows 账号保存的颜色、刷新间隔和宠物大小设置。

## 界面语言

在「设置 → 语言」里选择跟随系统、中文、日本語或 English。手动选择会在重启后保留。

## 查看额度

在这台 Windows 电脑上安装 Codex，并用自己的账号登录。程序通过本机 Codex 的 app-server 接口读取当前登录账号的额度。只有命令行工具时也能读取。若找不到程序，请在窗口中打开「设置 → 选择 Codex 程序…」，选择原生 codex.exe 或标准 npm 安装提供的 codex.cmd。WSL 中的登录和 Windows 原生 CLI 各自独立。

在 Windows 底部任务栏右侧的通知区域，电池以白字显示剩余百分比，默认随额度切换绿、橙、红色。左键或右键点电池或 Pet，菜单都会从任务栏上方向内展开。菜单首行把人物和电池放在同一个小胶囊里，其下显示当前账号的额度。点「打开额度窗口…」可查看重置时间，点「立即刷新」可更新读数。

「设置 → 电池颜色」提供按余额变色、青绿色和经典单色。勾选「紧凑托盘（仅电池）」可以为任务栏省下一个位置，窗口仍然显示 Pet。Windows 为电池和 Pet 各分配一个托盘位置，可把它们从隐藏图标区域拖到时钟旁并排摆放。图标的间距和排列由 Windows 控制。「托盘图标大小」调整格子内的图像，电池最小保留 16 像素，以便读数。

窗口沿用 Mac 版的额度卡片。大号数字显示剩余百分比，其下的细进度条和灰色文字分别表示余量和重置时间。双周期会在宽窗口中并排、窄窗口中上下排列。标题、正文和百分比按 Mac 版的层级排列。中文有独立的常规和中等字重，百分比采用等宽数字并与旁边的「剩余」对齐。字体随包提供，随应用加载。窗口会在启动时读取 Windows 的应用颜色模式。窗口会随内容调整高度，手动拉高或拉低后会保留这次调整。窗口使用账号实际提供的周期。只有周额度时会直接显示周额度，双周期账号可以指定一个，也可以跟随剩余较少者。按 F5 或点「刷新」立即更新，自动间隔可设为 30、60 或 120 秒。连接中断时会保留带时间标记的上次读数，托盘在数据过期后显示横线。按 Esc、「收起到托盘」或关闭窗口后，程序继续运行；再次双击 EXE 可打开原窗口。

## Pet 和应用图标

资源管理器中的 CodexBattery.exe 固定使用蓝色 Codex Pet 和电池组成的图标。启动时，窗口和托盘先显示这个蓝色 Pet。读到这台电脑的 ChatGPT / Codex 桌面端所选角色后，窗口和托盘会自动换成该角色。新电脑还没有选择记录时会继续显示 Codex Pet。在桌面端关闭 Pet 后，程序会收起人物。设置里可以隐藏人物、重新同步，或将窗口人物设为 32、48、72 点。

如果已选 Pet 的图像暂时读不到，可以在「设置 → ChatGPT Pet → 选择备用图片…」导入自己的 PNG 或 JPEG。应用还可以复用经核验的同账号、同角色、同一修订的个人头像。缺少个人图片时会收起头像，额度和电池照常显示。所选原图到位后会自动出现。设置可移除已导入的备用图片。要立即重试，可在 Windows 的 ChatGPT 桌面端打开该 Pet，再回额度窗口点「重新同步」。部分 WebP 原图依赖 Windows 的 WebP 解码器。

想让桌面上的快捷方式也显示自己的角色，可以打开「设置 → ChatGPT Pet → 创建跟随 Pet 的快捷方式…」。程序关闭后，该快捷方式会保留上次同步的图标。EXE 文件本身始终使用蓝色 Codex Pet。

## 验证与构建

双击 **Test.cmd** 可在本机复验。测试会短暂打开真实窗口，使用独立的测试账号数据和临时的 Pet 文件，无需登录 Codex。测试涵盖启动时的 Codex Pet、所选 Pet 缺图、自动切换角色和关闭 Pet，也会检查托盘菜单、紧凑模式、快捷方式和额度连接。

源码和 Build.cmd 随包提供。需要自行构建时先退出正在运行的程序，再运行 Build.cmd。用户设置位于 %LOCALAPPDATA%\CodexBattery，登录信息由本机 Codex 管理。
